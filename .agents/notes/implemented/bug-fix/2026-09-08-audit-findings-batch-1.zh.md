# Agent Note: Skeptic-confirmed audit findings, batch 1

Status: implemented

[English](2026-09-08-audit-findings-batch-1.md) | 中文

## 问题

应用层的一次只读审计产生了 15 项经 skeptic 复核确认的问题：每一项都通过了独立的代码复查，另有一份明确标记为未验证的暂缓清单，本次不做处理。确认的问题集中在四个边界上：模型控制的抓取可以访问非公网地址；主机 API 把 loopback 当作授权依据；工作区文件读取、预览与上传使用攻击者可控路径能够绕过的词法前缀检查；被执行产物（运行时包、PyPI 环境、办公运行时）在没有完整性校验的情况下安装。较小的确认项包括无界请求缓冲、先解码后限流的上传、无法中断的重连退避，以及预览竞态显示旧内容。

## 决策

每个问题都在其扼要处修复；暂缓清单保持不动。

模型控制的出口（`dsh-web-fetch-http`）默认拒绝非公网目标——loopback、私有网段、链路本地地址与云元数据——先解析 DNS，并对每个重定向跳逐跳重新校验。`egressAllowHosts` 是操作者为内部主机显式选择的例外，在加载时按裸主机名校验。残余的 DNS 重绑定风险记录在 provider 上。

主机 API 鉴权是启动时签发的按实例令牌（256 位、URL 安全），或来自部署配置的固定令牌；固定令牌必须通过长度与字符集检查，否则加载失败。信任围栏仍然判定 loopback 与声明 authority；令牌门与其并行，作用于 `/api` 路由与两条 WebSocket 下行链路。浏览器无法设置 WebSocket 请求头，因此下行链路与子资源 URL 用 `token` 查询参数携带令牌；入口 URL 用从不跨越 HTTP 边界的 `#token=` 片段携带令牌；每个服务端口一个 `0600` 令牌文件把凭证交给非浏览器自动化流程。

工作区收容收敛到一个 helper `anchorWorkspacePath`：尾部分隔符边界加符号链接解析，对越界与缺失文件给出唯一、不可区分的拒绝。预览、原始文件与缓存读取全部经过它；SVG 按附件提供，使同源导航无法执行存储型脚本，而 `<img>` 子资源引用不受影响。上传接收先校验 uploads 目录对象本身：移除被植入的符号链接，对非目录直接失败，然后才创建目录。

被执行产物先验后用，失败即关闭。`bwhale` 启动器在下载前解析必需的 SHA-256 摘要（发布字段或随附的 `.sha256` 文件），没有可用摘要材料的发布直接拒绝。办公 venv 从哈希锁定的依赖集合安装，带 `--require-hashes` 且不做安装器自升级；托管 LibreOffice 下载按 macOS 产物固定 SHA-256，在挂载任何内容之前对流式下载做校验。LibreOffice 固定值由改动作者从官方发布字节中提取，本仓库内未做独立复验。

资源与生命周期边界：HTTP 桥对每个请求体做全服务飞行中预算预留（超出返回 503），不再是无全局上限的按请求缓冲；图片接收在解码分配之前拒绝超限 base64 文本；连接控制器的 stop 通过单一生命周期令牌取消等待中的退避，重启后被孤立的旧循环看到已中止的令牌即退出，不会与新循环并存；产物预览携带按请求序号，迟到的旧响应无法覆盖新选择的渲染。

## 测试

每项修复都带有边界测试：出口允许/拒绝与逐跳复验；HTTP 与 WebSocket 路径上的无令牌、伪造令牌与查询携带凭证、令牌签发、弱固定值加载失败；同前缀兄弟目录、符号链接与 uploads 对象逃逸；SVG disposition；失败即关闭的摘要解析；两种安装脚本的锁字节复现；流式哈希校验；预算 503 与超额释放记账；解码前拒绝超限编码；退避中停止与重启不加倍；以及一个在旧共享标志下会失败的预览竞态套件。全量单元测试、类型检查与配置的 lint 通过；每个新模块的文件级覆盖率达标，其余既有缺口保持不动。

## 备选方案

**仅允许名单式出口（默认放行公网，拉黑已知恶意目标）。** 否决： hostile 目标无法枚举——元数据、链路本地与新的私有用途不断出现——而模型抓取的合法目标绝大多数是公网，因此默认拒绝加内部显式例外更偏向安全。

**只用请求头令牌，不用查询携带。** 否决：浏览器里 WebSocket 升级与子资源 URL 无法设置请求头，纯请求头方案会让下行链路失去保护或被迫接受更弱的检查。查询携带是窄的（精确的 `token` 参数），与请求头一样做常量时间校验。

**缺摘要时警告并继续。** 否决：下载路径上的警告会训练操作者忽略那个唯一能区分镜像被污染与下载缓慢的信号。没有 sidecar 的旧发布对新下载直接拒绝；已安装的运行时继续运行。

**顺手修复暂缓清单。** 否决：它们未经 skeptic 确认，其中几项命名的可能是代码本意的行为。每一项都需要独立复现之后再决定是否修复。

## 影响

抓取内部主机的 loopback 开发流程现在必须设置 `egressAllowHosts`；沙箱 shell 默认拒绝出口，不能收容出口的执行器在其下失败关闭。新 `bwhale` 安装拒绝 sidecar 之前的发布。所有第一方 UI 界面都会出示实例令牌，第三方前端必须同样出示，否则被围栏拒绝。快速重启不再让重连循环加倍，快速切换预览渲染的是当前文件。供应链姿态从只信传输变为固定字节，代价是每次上游发布都要更新固定值与锁标记。
