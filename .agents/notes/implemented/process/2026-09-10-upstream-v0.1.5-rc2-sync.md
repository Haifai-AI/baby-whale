# Agent Note: upstream v0.1.5-rc.2 content sync into Baby Whale

Status: implemented

English | [中文](2026-09-10-upstream-v0.1.5-rc2-sync.zh.md)

## Problem

Baby Whale forked from upstream DeepSeek Harness at `dsh-v0.1.1-rc.2`
(2026-08-21) and has since diverged as a fresh repository with unrelated git
history. Upstream moved ~10.5k files forward to the v0.1.5 line (new model
optimizations, a whole `apps/web` surface, the API layer restructured into
`packages/api/*-controller` Remote namespaces, chat rendering relocated from
`ui-conversation` into `ui-chat`, `dsh-mcp-client`, ACP and webhook stacks).
Every day of delay widened the porting debt for our own v0.2 work (MCP
client UI, browser use), so the sync had to happen now, while our delta is
still one release deep.

## Approach

A fresh clone of `Haifai-AI/baby-whale` (branch `sync/upstream-v0.1.5` off
`main`) fetched the upstream tags and created an explicit graft: our fork's
root commit was temporarily re-parented onto `dsh-v0.1.1-rc.2` with
`git replace --graft`, so `git merge --squash dsh-v0.1.5-rc.2` computed a
true three-way merge instead of an unrelated-histories collision. 94 files
conflicted; each was classified by whether a whale commit had touched it
since the fork (combine) or not (take theirs / accept their deletion), and
the combine set was resolved by hand. The graft was deleted before
committing, so the result is a single squash commit on our line.

## What came in from upstream

The `apps/web` application, `packages/api/{session-controller,
settings-controller,workspace-controller,workspace-files}` (upstream
dissolved `packages/host/apiproxy`), typert Remote namespaces, ACP +
subagent providers (claude-code/codex), webhooks, `dsh-mcp-client`, the
generated tsconfig alias registry, and the relocated chat architecture.

## What we preserved, and where it went

- Deliverables media UX (PR #10 family): the CallRecord state model with
  view-first + durable-args fallback survives in `turn-deliverables.ts`;
  `ProducedFiles`/`DeliveredCards`/`FilePreviewPane` stay our components.
  Upstream's present-open desktop actions were adopted around them.
- The PR #14 bootstrap-noise fix was re-applied onto the relocated
  `ui-chat` snapshot builder (`isBootstrapNoise` + `chatOrderKeys`).
- Whale packages survive; hand-written tsconfig aliases were re-added after
  upstream switched to a generated alias registry. The excel-analysis skill
  and the guardrails package were untouched.

## What was dropped, deliberately

- The managed LibreOffice runtime (sidebar card, `officeRuntime` API, soffice
  conversion, PDF-cache route): upstream removed the pipeline it hung on.
  Office previews now parse only (xlsx grid/charts, pptx/docx text, media
  identity streaming with Range support); pixel-true rendering returns with
  the planned preview-studio work.
- The artifacts RPC namespace: re-hosted as three authenticated GET routes
  in the session controller (`/api/artifacts.list`, `/api/artifacts.preview`,
  `/api/artifacts.raw`), keeping the Range-capable media serving; client
  callers now use plain fetch.

## Migration notes

`packages/host/apiproxy` remains as a minimal whale-only package hosting the
preview parsers; the artifacts routes live in
`packages/api/session-controller/src/artifacts.ts` (mounted as
`SessionArtifacts` beside upstream's `SessionMediaReferences`).
