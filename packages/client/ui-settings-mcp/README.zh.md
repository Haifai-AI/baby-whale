# @deepseek-ai/dsh-client-ui-settings-mcp

English | [中文](README.md)

Web 设置 → 插件中的 **MCP 服务器** 标签页：[`whale-mcp`](../../../whale/mcp/README.md) 宿主插件的管理界面。用户可以添加、编辑、启用、导入、重连和删除 MCP 服务器；标签页展示每台服务器的实时连接状态及其当前提供给模型的工具。

## 这里显示什么

该标签页向插件区注册一个 `settings.plugins.tab` 贡献（`id: mcp`），渲染为头部行（服务器计数、**添加服务器**、**导入 JSON**）、空状态，以及每台已保存服务器一张折叠卡片。收起状态显示名称、传输徽章（本地进程 / HTTP）、带本地化标签的状态圆点（`已连接` / `连接中` / `连接失败` / `已停用`）和展开箭头。展开后显示目标行（命令加参数，或端点 URL）、`failed` 状态下的失败信息、以紧凑芯片呈现的工具列表（为便于阅读剥掉 `mcp__<name>__` 前缀），以及操作行：启用开关、**编辑**、**删除**（内联确认），启用状态的服务器另有**重连**。

状态来自每次挂载/重试时的一次性 `mcpStatus.list()` 读取，并在每次保存/重连后于 +600 ms 与 +2500 ms 重新读取，让 `连接中` 的圆点无需推送信道也能落定。

## 写入

标签页绑定 `mcp` 设置作用域（`ctx.settingsScope`），并整体写入 `servers` 数组——每次保存都是一次带修订围栏的 `settings.mutate` 字段写入，其结果折回共享镜像。未落地的保存（并发编辑、schema 拒绝）会内联报告而不是被丢弃。编辑在本地草稿中进行；名称不符合模型可见契约或传输必填字段缺失时**保存**禁用。**导入 JSON** 解析粘贴的生态 JSON——claude_desktop_config 风格的 `mcpServers` 块或裸服务器映射——生成新条目，名称合法化并处理重名后缀。

## 模型体验

无；本包渲染配置界面。其写入内容仅通过 whale MCP 管理器及其桥接抵达模型。

#### KV Cache 影响

无。

## 已知限制与后续工作

- **每次挂载或重试一个快照** — 状态不推送；保存后的定时重读覆盖常见的落定窗口。
- **无保存前连接测试** — 保存后的校验依赖状态圆点加**重连**。
