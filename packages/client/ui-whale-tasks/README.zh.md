# `@deepseek-ai/dsh-client-ui-whale-tasks`

[English](README.md) | 中文

Web GUI 的 Whale 任务板：一个键控 chat node（`whale-task-board`），把每份 `whale/task-board` 快照（由 `@deepseek-ai/dsh-whale-core` 在每次任务变更或投递后发出）渲染成紧凑的定时任务列表——状态圆点、名称、计划摘要和下次运行时间。

任务板是对持久事件的纯渲染：回放会从会话日志重新计算它，快照缺席时则不渲染任何内容。

## 组合方式

本包声明 `dsh.client`（platform 为 `web`）、发布 `./client`，并注册事件定义、键控 renderer 以及 `whale-tasks` 字典命名空间。移除它的 roster 行即可关闭任务板。

## 渲染约定

每个 `whale/task-board` 事件都成为独立节点，`id` 取该事件的 `seq`，并以 `publication: 'immediate'` 发布，因此这份投影不含任何 fold：最新快照以新卡片的形式到达，而不是更新上一张卡片；回放日志会复现同一串卡片。空快照仍会渲染卡片，只是用空状态文案替代任务行。

每行绘制本地化的状态圆点（`active`／`paused`／`done`）、任务名称、计划摘要与本地化状态，以及一行下次运行时间——本地化的时刻、`nextRunAt` 为 null 或无法解析时的占位符 `—`，或活跃任务超过计划时刻 90 秒后的「已错过」文案。同一个 90 秒窗口也约束完成通知：每份落定快照至多触发一次，且仅在 `Notification.permission` 已为 `granted` 且标签页处于隐藏状态时触发。

## 模型体验

### Whale 任务板 chat node

#### 模型看到的内容

没有任何内容：任务板渲染的是 `@deepseek-ai/dsh-whale-core` 在每次任务变更或投递后发出的整值 `whale/task-board` 会话事件。该事件是仅为界面记录、供回放重建卡片的日志态数据；本包不注册提示词段落、工具定义或结果文本，定时能力只有经该宿主包的 `whale_task_*` 工具结果才会抵达模型。

#### Token 影响

直接开销为零：该节点不增加提示词文本，也不增加工具定义，其渲染的持久事件从不参与任何已组装的请求。

#### KV Cache 影响

相互独立：本包既不组装也不发送提供方请求，因此挂载或移除任务板只会改变浏览器侧的树，不会使可复用的前缀失效。

## 已知限制与暂缓事项

- **任务板是只读的**：任务行不带任何操作；创建、暂停与结束任务都通过 `whale_task_*` 工具完成。
- **每份快照一张卡片**：每份快照都是以其事件 `seq` 为 key 的独立 chat node，因此一串密集变更会留下一串卡片，而不会折叠成单一实时看板。
- **只绘制下次运行时间**：任务行没有上次运行一行；`lastRunAt` 虽会到达节点，却只驱动通知启发式，字典里还留着一个未被渲染的 `board.lastRun` 键。
- **「已错过」是客户端侧的 90 秒启发式判断**：是否错过下次运行由浏览器时钟判定，因此计划时刻刚过的任务仍显示字面时刻，而宿主调度器可能已经迟到。
- **完成通知是尽力而为的**：只有当快照落定于某条 `lastRunAt` 之后 90 秒内、权限已授予且标签页隐藏时才会触发；这里没有推送信道，因此标签页可见时到达的投递会悄无声息地过去。
